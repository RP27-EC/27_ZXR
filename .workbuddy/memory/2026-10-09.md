# 2026-10-09 工作日志

## 调研：真车 pitch 重力前馈是否按机械/陀螺仪模式分开做

**结论：没有分开。** 真车 `hole_infantry/hole_infantry-hole_infantry_up/Application/ModuleLayer/gimbal.c`：

- 前馈在模式 switch **之前**统一算一次（`:524 gravity_f_cal(gimbal);`），
  然后 `G_MEC` 分支（`:535`）和 `G_GYRO` 分支（`:546`）**加的是同一个 `gravity_f`**。
- 前馈实现（`:576-584`）：
  ```c
  static void gravity_f_cal(gimbal_t *gimbal)
  {
      double middle_angle = 2.678706762f - PITCH_MOTOR_ANGLE_MIDDLE;  // = 0.0856
      float k = 4.2072;
      float b = -2.496;
      gimbal->base_info.gravity_f = cos(gimbal->base_info.pitch_motor_angle - middle_angle)*k+b;
  }
  ```
- **角度源是电机编码器控制角 `pitch_motor_angle`（水平=0，弧度），不是 IMU pitch（度）**。
  即陀螺仪模式下 pitch 反馈用 IMU 角，但前馈仍用编码器角——两者不是同一个角度源，真车就这么混用。

**为什么能成立**：
- 步兵平地行驶，底盘俯仰很小 → 相对底盘角 ≈ 相对大地角，误差可忽略；
- 两套 PID 的内环输出单位一致（mec_inner / gyro_inner 的 out_max 都是 10），前馈是叠加在输出上的同一物理量。

**对本项目的启示（重要）**：
- 我们的 `Gimbal_Pitch_Gravity_FF()` 用 `Gimbal_Real_Angle(axis) - GIMB_PITCH_GRAV_CENTER`，
  `Gimbal_Real_Angle` = `motor_angle - ZERO_OFFSET(2.59309077)` = 编码器控制角，
  与真车 `pitch_motor_angle - 0.0856` **等价**（水平时 d=-0.0856，ff≈1.69 N·m，一致）。
- ⇒ **沿用真车做法：前馈固定用编码器控制角，不随模式切换**。好处：K/B/θc 标定一次通用、
  单位统一（弧度）、代码零改动。
- ⚠️ 坑：K/B/θc 是**绑定角度源**标定的。若把前馈改成用 IMU 大地 pitch，
  必须重新标定 K/B/θc，且要把 IMU 的度转成弧度——不划算，不建议。

## 用户决策：IMU 随云台动 + 采用 EKF + 朝向按真车
- **IMU 与 C 板一起装在上板、随云台动**（用户确认）→ 陀螺仪模式可直接把 IMU 角当云台大地角，
  不需要"IMU 角 + 编码器相对角"合成。架构不确定性消除。
- **采用 EKF**（不用 Mahony）→ 切换 `rp_config.h:19/21` 为 `IMU_USE_MAHONY 0 / IMU_USE_EKF 1`
  （与下板 27_ZXR 的 `:33/35` 一致）。好处：`YawTotalAngle`（多圈）可用，解决本项目 yaw 无限转的
  多圈缺口；且 EKF 用 `micros()` 算真实 dt，没有 Mahony 的 halfT 写死问题。
  F4 跑 EKF 可行（真车 hole_infantry_up 就是 F4+EKF）。
- **朝向标定按真车**：真车 `bmi.c:39-44` 与 `bmi_EKF.c:79-88` 两份**都是 arz=180, ary=0, arx=0**；
  本项目模板两份都是 arz=90。⇒ 切 EKF 后把 `bmi_EKF.c:39` 的 `EKFgim_trans.arz` 改成 180。
  ⚠️ 该值取决于芯片物理贴装方向，必须串口实测复核（水平时 pitch≈0，否则在 90/180/0 间试）。

## EKFgim_trans 是什么（已查证，无隐藏坑）
- 类型 `gimbal_transform_t`（bmi.h:38-44）：字段 `arz`(陀螺仪x轴与roll轴夹角,度)、
  `ary`(x轴与yaw轴夹角)、`arx`(y轴与yaw轴夹角)、`trans[9]`(3x3 旋转矩阵)。
- 作用：BMI088 芯片自身坐标轴与云台 roll/pitch/yaw 轴不重合 → 用这三个安装角按 Z-Y-X 顺序
  生成旋转矩阵（`transform_init`，bmi.c:89-110），把原始 gyro/acc 旋转到云台坐标系，再送 EKF。
- **生效链路（已验证）**：`transform_init(&EKFgim_trans)` 只在 EKF 分支调用（imu_sensor.c:98），
  把矩阵绑定到全局 `Trans`；`Vector_Transform()`（imu_sensor.c:189，无条件调用）用这个 `Trans`
  做乘法。⇒ **切 EKF 后改 `EKFgim_trans` 有效**（不是改 `gim_trans`）；
  当前用 Mahony 时生效的才是 `gim_trans`（bmi.c:39，arz=90）。
- EKF 初始化参数（imu_sensor.c:102）：`IMU_QuaternionEKF_Init(init_quaternion, 10, 0.001, 8000000, 1)`
  → measure_noise=8e6（注释推荐 1e6，偏大=更不信任加速度计）、lambda=1（注释推荐 0.9996），
  切换后需实测收敛速度，必要时按注释回调。
