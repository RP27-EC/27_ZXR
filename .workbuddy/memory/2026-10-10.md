## 陀螺仪模式：最终实施清单（已结合用户决策定稿）

用户已拍板的三项前提：
1. IMU 与 C 板同在上板、**随云台动** → 自稳可直接用 IMU 角，不需"IMU+编码器"合成。
2. 采用 **EKF**（非 Mahony）。
3. 朝向标定**按真车** `arz=180`（真车 bmi.c:39-44 与 bmi_EKF.c:79-88 两份都是 180；本项目模板是 90）。

### 实施顺序（关键：先切算法并验证，再接控制）
- **阶段0 切 EKF**：`rp_config.h:19/21` 改 `IMU_USE_MAHONY 0 / IMU_USE_EKF 1`；
  `bmi_EKF.c:39 EKFgim_trans.arz` 改 180；核对 EKF 参数
  （`imu_sensor.c:102` 现为 10, 0.001, 8000000, 1；注释推荐 measure_noise=1e6、lambda=0.9996）。
  编译下载确认不卡死、IMU 初始化正常。
- **阶段1 验证**：串口打 Yaw/Pitch/YawTotalAngle（转弧度）+ 电机编码器角对照。
  判据：水平时 pitch≈0；固定底盘只转云台时 yaw 跟着变。不对就在 90/180/0 间试 arz。
- **阶段2 模式与反馈源**：加 `GIMB_MODE_GYRO`；定档位；`Gimbal_Real_Angle` 按模式分支；
  度→弧度；方向/符号校准（pitch 取负、yaw 方向）。
- **阶段3 PID**：加陀螺仪组参数宏 + 切档重载（切档已有 pid_clear，一组对象够用）。
- **阶段4 切换/限幅/多圈（最易漏）**：无扰切换（target=当前 IMU 角，非固定常量）；
  err-wrap 按模式（陀螺仪连续角不 wrap）；多圈用 `YawTotalAngle`；pitch 限位按模式换算。
- **阶段5 保护**：IMU 健康检查（err_code + cali_end）；异常降级策略。
- **阶段6 调参**：两套分别调；观察 yaw 漂移；自稳实测。
- **重力前馈不用改**（真车两模式共用，前馈固定用编码器控制角，K/B/θc 不重标定）。
